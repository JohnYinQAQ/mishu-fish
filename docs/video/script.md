# 秘书鱼 v0.2.0 宣传片脚本

总时长目标：**3 分钟**（B 站完播率最好的区间是 2–4 分钟）
画幅：1920×1080 或手机竖屏 1080×1920（二选一，别中途换）

---

## 0:00–0:15 钩子

**画面**：ipad主界面，镜头停在她发来的那条消息上，慢慢放大。

**口播**：

> 这是一条微信消息。
> 不是群发的，也不是定时的模板。
> 它知道我今天有什么事，知道我几点睡，还知道主动通知我

**要点**：前 3 秒必须让观众看到「微信 + 秘书鱼」的聊天界面，不要先放 Logo。

---

## 0:15–0:40 是什么

**画面**：切电脑，展示 DSH 设置页的「人设」部分。

**口播**：

> 她叫秘书鱼，是一个跑在 DeepSeek Harness 上的插件。
> 你用微信小号扫码登录，她就住进了你的微信。
> 人设、语气、称呼、禁用词，全都能改。

**注意**：这里要出现「设置页」画面，让观众知道这不是一个 App，而是**可配置的**。

---

## 0:40–1:20 记忆：她记得住

**画面顺序**：

1. 微信里问一句「我之前说过要做什么来着」
2. 她回答出具体的事
3. 切设置页「记忆」→ 事实卡那几行

**口播**：

> 普通聊天机器人，说完就忘。
> 她每天凌晨五点会把当天对话整理一遍：写一条摘要，更新一张「事实卡」。
> 事实卡里是长期成立的你——你的习惯、你的偏好、你在忙什么。
> 每条消息都会带上这几行，所以她不用你重复自我介绍。

**画面提示**：事实卡要放大，让观众看清「- 主人自称二次元」这种真人味的内容。

---

## 1:20–1:55 日程：一句话就记下

**画面**（连续三个动作，节奏要快）：

```
① 发：记一下：周五下午三点交报告
② 发：我今天有什么安排
③ 发：报告交了
```

**口播**：

> 记日程不用开 App。
> 说一句「记一下：周五三点交报告」，她就记下了。
> 问「我今天有什么安排」，她列给你。
> 说「报告交了」，她自己标记完成——不用你点任何按钮。

**进阶一句**（可选，字幕打出）：

> 触发词也可以关掉，让她自己判断哪句话该记。

---

## 1:55–2:25 习惯：她能从日程里发现规律

**画面**：

1. 微信连发三次「记一下：每周三下午五点滑冰」
2. 切设置页「习惯」→ 出现「待确认」
3. 点「确认」
4. 展示已启用列表：每周三 17:00，提前 30 分钟

**口播**：

> 更进一步的，她会自己发现规律。
> 你在日程里反复出现「每周三下午五点滑冰」，她就会在设置里给你一个候选。
> 你点确认，她才会在每周三四点半问你一句：是不是准备去滑冰了。

**关键**：这里要强调「候选制」——**不确认就不打扰**。这是这个项目和其他提醒工具最大的区别。

---

## 2:25–2:45 作息与问候

**画面**：设置页「作息」→ 当前画像（通常 07:45 起、23:30 睡）+ 微信里的早晚消息。

**口播**：

> 她还会学你的作息。
> 从你发消息的时间和一句「晚安」，推算出你几点睡、几点起。
> 然后早上七点半叫你一声，晚上十一点提醒你别熬。

---

## 2:45–3:00 收尾

**画面**：GitHub 仓库页 → 网站首页 → 片尾卡。

**口播**：

> 完全开源，MIT 协议，代码和下载都在 GitHub。
> 只有一点要说清楚：用的是非官方接口，随时可能失效。
> 想试的话，链接在简介里。

# 录制前准备

## 清场

```bash
# 清掉测试数据，让界面干净（会丢历史，先备份）
cp -r ~/.dsh/mishu-fish ~/mishu-fish-backup
```

## 造素材（每段都是真的，不是摆拍）

```bash
# ① 早间问候：立刻让她发一条
touch ~/.dsh/mishu-fish/run-greeting

# ② 晚间问候
echo evening > ~/.dsh/mishu-fish/run-greeting

# ③ 周报
touch ~/.dsh/mishu-fish/run-weekly
```

## 手机画面怎么录

- **iPhone**：数据线连 Mac → 打开 QuickTime → 新建影片录制 → 摄像头选 iPhone → 录完直接存
- 或者手机自带录屏，AirDrop 到 Mac

## 电脑画面

- `Command + Shift + 5` → 录制所选部分 → 1080p
- 录之前把浏览器书签栏隐藏（`Command + Shift + B`），看起来干净

## 打码

- 微信昵称、头像（用模糊工具或直接裁掉）
- 任何真实姓名、学校、地址
