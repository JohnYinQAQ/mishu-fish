# 冒烟测试（发布前手动走一遍）

目标：确认一个**从零开始的人**照着 README 能跑通。全程约 15 分钟。

## 0. 准备

- [ ] 一台没装过本插件的机器（或删掉 `~/.dsh/mishu-fish/` 与 profile 里的软链）
- [ ] DSH 能正常启动，模型可用
- [ ] 一个能扫码登录的微信

## 1. 安装

- [ ] `pnpm install && pnpm build` 不报错
- [ ] 按 README 把插件加进 profile 的 `dependencies` + `bundles`
- [ ] 重启 DSH 后，设置里出现「秘书鱼」

## 2. 登录

- [ ] `pnpm login` 出二维码，扫码后 `~/.dsh/mishu-fish/credentials.json` 存在且权限 0600
- [ ] 设置页状态显示账号与「窗口剩余」时间

## 3. 基础对话

- [ ] 微信发「你好」，10 秒内收到回复
- [ ] 回复长度不超过 `maxTokens` 设定，没有被截断
- [ ] 日志面板能看到一条 `in` + 一条 `out`

## 4. 日程

- [ ] 「记一下：明天 15:00 开会」→ 回复里有「记下了」和时间
- [ ] 「我今天有什么安排」→ 列出刚才那条
- [ ] 「开会交了」→ 标记完成

## 5. 记忆

- [ ] 连续聊 3 轮，`~/.dsh/mishu-fish/memory/YYYY-MM-DD.jsonl` 有对应记录
- [ ] 设置页「记忆」里能看到最近对话条数

## 6. 主动消息

- [ ] `echo evening > ~/.dsh/mishu-fish/run-greeting`，15 秒内收到晚间问候
- [ ] 问候内容包含当天日程或作息参考，不是模板腔
- [ ] 同一窗口内不会重复发第二次

## 7. 习惯

- [ ] 说三次「记一下：每周三 17:00 滑冰」
- [ ] 设置页「习惯」出现候选，点「确认」后变已启用
- [ ] 手动改提前量，列表显示跟着变

## 8. 异常

- [ ] 断网 30 秒，日志出现「拉取失败」，恢复后自动继续
- [ ] 重启 DSH，进程能续读游标，不重复回旧消息

## 9. 收尾

- [ ] 确认发布物里没有 `.data/`、`.tmp/`、`node_modules/`
- [ ] 确认 README 里没有个人绝对路径
